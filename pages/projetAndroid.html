📱 Application Android – Suivi GPS entre utilisateurs

Développement from scratch d’une application mobile Android en Java, et d'une API en PHP, permettant aux utilisateurs inscrits de suivre et d’être suivis mutuellement via une partage sécurisé de position GPS, sur base de consentement.



⚙️ Architecture & Technologies
  • Android (Java) : développement natif de l’interface et des fonctionnalités mobiles
  • API RESTful : gestion des échanges entre l'application et le serveur
  • SGBD : MySQL
  • Sécurité : contrôle d’accès aux données partagées, gestion des permissions
